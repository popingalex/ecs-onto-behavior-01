## 1. 核心决定

根据最新报告,v0.7-H 已声明通过 138 项测试(0 失败),3208/3208 项逐帧写入值一致,390/390 条来源 System ID 一致。历史帧回放检查、动态 System 发现、P12 原生只读计划和来源分级已报告完成。不要重新实施 H0–H3。

- **W(模型写入)**:本地 ModelPatch 已有初步协议和 4 项测试;推进原生引擎隔离事务化提交。

- **G(地图)**:复用 `map-engine-v2`,优先评估 iframe/微前端,工作台只承担宿主与联动。
- **T(性能)**:独立新版引擎/数据库运行 TraceRecorder,不操作现有 18080 服务。

## 4. W0/W1:模型安全编辑和原生提交

### W0(立即可做,不写引擎)

复用已有 `modelPatch/protocol.ts`,不建立平行 DTO。根据 `/cm` 真实代码完成:

- `ModelPatch`:expectedRevision、源对象稳定 ID、操作、单位/值语义、idempotencyKey;
- `validate`:类型/量种/组件装配/引用/权限;
- `dryRun`:按源版本预览差异,零持久写入;
- `apply`:仅作为**待引擎实现的候选协议**;
- `getStatus`:用于提交超时后的幂等结果查询。

补本地负例:旧版本冲突、同幂等键不同请求、部分操作失败、引用对象删除、UNSET 与 null 混淆。

### W1(硬闸门:用户授权隔离引擎+独立 PG)

不得通过现有 `/cm` 连续直写再"事后校验"。引擎侧需支持统一事务内的:

- revision 原子检查与冲突拒绝;
- 多操作全部提交或全部回滚;
- 幂等键及请求 digest 检查;
- 引用/单位/值域/组件要求校验;
- 成功产生**原生新 revision**,工作台草稿 ID 不冒充原生版本;
- 并发失败、重复请求、半途进程终止的可恢复性。

**首个试验用已有隔离场景中引擎原生支持修改的简单参数;动态新增实体/组件只有在真实 schema 支持且已审计时再做。**

验收:W-01 dryRun 无写入;W-02 成功原生 revision;W-03 stale/非法引用/单位拒绝;W-04 幂等;W-05 故障原子性;W-06 历史旧版本不变;W-07 双侧读取一致;W-08 未触共享服务。

## 5. X0/X1:原生 System 编辑边界

### X0(立即可做,只读语义分析)

阅读原生 System 注册、stage/tick、query、write/flush/barrier 源码,明确**帧内写传播**真实边界,与工作台的 `State[n]`/order-only 语义对比,形成版本化 `ExecutionSemanticsProfile`。

将 System 分为:
- S0:原生黑盒,只读展示和来源分析;
- S1:原生参数可映射,可编辑受支持字段;
- S2:结构化图可编译,必须有真实执行器与完整类型/边语义。

建立 native→IR 的**只读**映射与不兼容诊断,不得把原生顺序边直接转为 mock 的 order-only,不得把展示的 9 阶段/17 个 System 视为可部署图。

### X1(引擎支持与授权后)

native→IR→native 无损往返,原生校验,固定真实场景双侧对照(状态变化、来源 System、适用级别的 trace),不兼容即拒绝编译。真实发布还依赖 W1 的版本化提交协议。

## 6. G0/G1:MapEngine 接入

### G0(可以立即做)

复用 `mapMount/protocol.ts` 的已有 3 项替身测试,核对 `map-engine-v2` 是否有可直接使用的微前端/iframe/插件入口。先定义:

- 协议版本、允许 origin、初始化/卸载、超时和错误;
- 源实体 ID ↔ 地图 feature ID;
- sceneRevision、simulationId、branchId、frame/viewCommit;
- 选择回环 correlationId、防陈旧异步响应;
- coordinateFrame、轴顺序、经纬度/局部坐标与高程基准;
- null 位置不渲染、`[0,0,0]` 是合法位置;
- 原引擎路线/位置为权威,地图只做可视化。

不能把 `transform/position` Vec3 自动当成 lon/lat/height。

### G1(地图工程/接口评审批准后)

在 P20 宿主内真实挂载 MapEngine:工作台选择实体→地图定位→地图点击→P22/P24 选中→切历史/分支位置一致。失败时明确标未连接,不绘制假空间结果。

## 7. T:逐 System TraceRecorder

当前 N-11 NOT_RUN 符合安全边界。未经授权不能重启含历史会话的 18080 服务,也不能对共享 PG 迁移。

在独立端口、独立数据库和固定新二进制上,记录每 frame/stage/System 的原始耗时、版本、实体批次,并比较 trace 开/关的执行开销。缺少数据就显示"不支持/未启用",不可平均分配 total 时间制造性能曲线。
